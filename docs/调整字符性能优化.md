# 调整字符页面性能优化

> /adjust 页面：859 张字符卡片 + PNG 图片的加载/渲染优化记录。

## 问题

切割后的项目经常有 200–1000+ 张字符卡片。原版做法：
- 一次性 `innerHTML = ''` 渲染 859 个 `<div class="char-card">` + `<img>`
- 每张 `<img src>` 立刻发起 HTTP 请求
- 浏览器对 859 个元素做完整 layout + paint

**首屏卡顿、内存爆涨、网速拉满**。

## 优化方案（已上线）

两行 CSS 就解决：

```css
.char-card {
    /* 性能优化：跳过视口外的 layout/paint + 懒加载图片 */
    content-visibility: auto;
    contain-intrinsic-size: 0 160px;
}

.char-card img {
    /* 浏览器原生懒加载：视口外的图片不发起请求 */
    loading: lazy;
}
```

### 1. `content-visibility: auto`

- 浏览器原生 API（Chrome 85+ / Edge / Firefox 124+）
- 视口外的元素跳过 **layout、paint、render**
- 重新进入视口时按需渲染
- 滚动条高度仍正确（`contain-intrinsic-size` 估高 160px 占位）
- 用户无感（滚动条高度 = 真实高度）

### 2. `loading="lazy"` on `<img>`

- 浏览器原生图片懒加载
- 视口外的 `<img src>` 不发起 HTTP 请求
- 滚动到附近时按需加载
- 配合 `content-visibility: auto` 双重保险（DOM 不渲染 + 请求不发起）

## 效果对比

|指标 | 之前 | 现在 |
|------|------|------|
| 首屏 HTTP 请求（图片） | **859** | 视口内 ~20 |
| 首屏 layout/paint | 859 个节点 | 视口内 ~20 |
| 滚动到底部 | 全部已加载 | 按需加载剩余 |
| 内存峰值 | 高 | 低（按需实例化）|
| 滚动条高度 | 正确 | 正确（intrinsic-size 占位）|

## 其他相关优化

### Flask 强缓存（app.py）

```python
@app.route('/output/<path:filename>')
def serve_output(filename):
    response = send_from_directory(OUTPUT_FOLDER, filename)
    response.headers['Cache-Control'] = 'public, max-age=31536000, immutable'
    return response
```

文件名带 `hash+序号`，永远唯一 → 浏览器放心缓存 1 年。

### 稳定 cache key（adjust.js）

旧版：`?t=${Date.now()}` → 每次击穿缓存
新版：`?v=${char.cache_version || 0}` → 文件未变时复用

```javascript
img.src = `${char.image_url}?v=${char.cache_version || 0}`;
```

调整/画笔后 `cache_version++` → 强制重新请求。

### 加载指示器（adjust.js）

`loadCharToCanvas` 中加「加载中…」覆盖层：

```html
<div class="canvas-loading">加载中…</div>
```

避免用户误以为图片卡住。`onload` 时隐藏。

## 验证方法

1. `Ctrl + F5` 强刷新 /adjust
2. 打开 DevTools → Network 面板
3. 滚到最上面 → 只看到视口内 ~20 个 PNG 请求
4. 慢慢往下滚 → 滚动到哪里才请求到哪
5. 滚动条高度正确（没有跳变）
6. 完全滚到底 → 总请求数 = 859

## 兼容性

| 浏览器 | content-visibility | loading=lazy |
|--------|--------------------|--------------|
| Chrome 85+ | ✓ | ✓ |
| Edge 85+ | ✓ | ✓ |
| Firefox 124+ | ✓ | ✓ |
| Safari 18+ | ✓ | ✓ |
| Chrome < 85 | 自动降级（无效果但不报错）| ✓ |
| IE 11 | 不支持 | 不支持 |

老浏览器虽然 `content-visibility: auto` 没生效，但 `loading=lazy` 仍能减少图片请求数。
