# 文本框检测说明

> 切割布局里的「绿色虚线」是怎么来的？答案：**不是 OCR**，是 OpenCV 轮廓检测。

## 现状：没有用 OCR

虽然模块名叫 `ocr_handler`、函数叫 `detect_text_boxes`，且 `requirements.txt` 列了 `easyocr==1.7.1`，但项目代码**完全没有调用 EasyOCR**：

```bash
$ grep -rn "easyocr" --include="*.py" .    # 排除 .venv 后
# 无结果
```

实际检测是 [utils/ocr_handler.py](../utils/ocr_handler.py) 里的 OpenCV 轮廓算法。

## 算法：OpenCV 轮廓检测

### 步骤

```python
def detect_text_boxes(img, min_area=100, max_area_ratio=0.3):
    # 1. 膨胀（3x3 核）—— 把同一字的离散笔画连成一个整体
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
    dilated = cv2.dilate(gray, kernel, iterations=1)
    
    # 2. 找外轮廓
    contours, _ = cv2.findContours(dilated, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    
    # 3. 每个轮廓 → boundingRect → 过滤
    for contour in contours:
        x, y, w, h = cv2.boundingRect(contour)
        if area < 100 or area > img_area * 0.3: continue
        if w/h > 5 or w/h < 0.1: continue
```

│   │ │ │  │       │
│   └─┘ └──┘       │
│                  │
│   ┌──┐ ┌─┐      │
│   │  │ │ │       │
│   └──┘ └─┘       │
└──────────────────┘
        ↓ 膨胀（dilate）
┌──────────────────┐
│   ┌────┐ ┌────┐  │   ← 同字笔画被连成一个轮廓
│   │    │ │    │  │
│   └────┘ └────┘  │
│                  │
│   ┌────┐ ┌────┐  │
│   │    │ │    │  │

## 为什么不用 EasyOCR？

[ocr_handler.py:9](../utils/ocr_handler.py#L9) 注释直接说明了：

> "对于书法图片，这种方法比 OCR 更准确"

| 维度 | OpenCV 轮廓 | EasyOCR |
|------|------------|---------|
| 识别准确率（书法字）| ✅ 轮廓即边框，不依赖识别 | ❌ EasyOCR 对草书/行书识别率低 |
| 速度 | ✅ 几毫秒 | ❌ 加载 PyTorch 模型，慢数十倍 |
| 体积 | ✅ 无额外依赖 | ❌ 118 MB torch + 1.3 MB torchvision |
| 用途 | 找「这块有字」| 识别「这块是什么字」|

**关键区别**：

- 切割布局只需要"字的边界框"，**不需要知道是什么字**
- EasyOCR 解决"这块是什么字"的问题——本项目暂时用不上
- 后续如果有"按字标注"的需求（识别具体是哪个汉字），再启用 EasyOCR

## EasyOCR 是死代码

`requirements.txt` 里的 `easyocr==1.7.1` **从未被项目代码调用**。可以安全删除：

- 减少 uv 安装时间（约 2 分钟，120 MB 下载）
- 减小打包后的 exe 体积
- 降低 venv 大小

**清理方式**：编辑 `pyproject.toml` 删除 `easyocr==1.7.1`，然后 `uv lock && uv sync` 重新生成锁文件。

## 检测参数

| 参数 | 默认值 | 含义 | 调参建议 |
|------|--------|------|---------|
| `min_area` | 100 像素² | 最小文本框面积 | 草书/行书连笔多 → 调高（如 200） |
| `max_area_ratio` | 0.3 | 最大占图比例 | 有大块印章/题款 → 调低（如 0.15） |
| 长宽比 | 0.1 ~ 5 | 过滤太扁/太窄的笔画团 | 极扁的横画/极长的撇捺 → 放宽（如 8） |

调用位置：[app.py:114](../app.py#L114)、[app.py:138](../app.py#L138)、[app.py:738](../app.py#L738)、[/api/detect](../app.py)。

## 检测结果用途

每个检测到的文本框 `{x_min, y_min, x_max, y_max, width, height, center_x, center_y}` 用于：

1. **可视化**：[static/js/layout.js](../static/js/layout.js) 的 `drawTextBoxes()` 绘制绿色虚线
2. **切割线推导**：[utils/cut_analyzer.py](../utils/cut_analyzer.py) 计算红/蓝线
3. **保存到会话**：`session_data['boxes']`，跨页面共享
