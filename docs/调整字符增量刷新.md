# 调整字符增量刷新

> /adjust 页面 confirm 调整后只刷新当前修改的卡片，不重渲全部 858 张。

## 问题

之前 confirm 后调用 `renderCharacterGrid()` 全量重建 859 张 `<div class="char-card">`：

- 859 个 DOM 节点被销毁并重建
- 859 个 `<img>` 标签 URL 重新生成（实际只 1 张变了）
- layout/paint 全部重做
- 即使其他 858 张没改动，也被强制重画

**用户感知**：confirm 一下，等 0.5–2 秒才能看到更新，过程中页面空白/闪烁。

## 方案：单卡更新

### 数据结构

每张卡片有稳定的 `data-char-id`：

```html
<div class="char-card" data-char-id="0_42">  <!-- "{strip_index}_{char_index}" -->
    <img class="char-image" src="...">
    <div class="char-status adjusted">已调整</div>
</div>
```

定位单卡：CSS selector 直接命中

```javascript
const card = document.querySelector(`.char-card[data-char-id="${strip_index}_${char_index}"]`);
```

### 增量更新函数

```javascript
// adjust.js — 只刷新单张卡片
function reloadOneCharCard(char) {
    if (!char || !char.filename) return;

    const card = document.querySelector(
        `.char-card[data-char-id="${char.strip_index}_${char.char_index}"]`
    );
    if (!card) return;

    // 1) 更新图片 src（用最新 cache_version 强制重新请求）
    const img = card.querySelector('img.char-image');
    if (img) {
        const baseUrl = char.image_url || `/output/${state.imageHash}/${char.filename}`;
        img.src = `${baseUrl}?v=${char.cache_version || 0}&t=${Date.now()}`;
    }

    // 2) 重评估状态标签（已调整/空白），其他卡片不动
    const oldBadge = card.querySelector('.char-status');
    if (oldBadge) oldBadge.remove();

    const hasAdjust = (char.adjust_top || 0) > 0 || (char.adjust_bottom || 0) > 0 ||
                      (char.adjust_left || 0) > 0 || (char.adjust_right || 0) > 0;
    if (hasAdjust) {
        const status = document.createElement('div');
        status.className = 'char-status adjusted';
        status.textContent = '已调整';
        card.appendChild(status);
    } else if (char.is_empty) {
        const status = document.createElement('div');
        status.className = 'char-status empty-slice';
        status.textContent = '空白';
        card.appendChild(status);
    }
}
```

### 触发点

`confirmAdjust` 成功后调用 `reloadOneCharCard(canvasState.char)`：

```javascript
const data = await response.json();
hideLoading();
if (data.success) {
    showToast('已保存调整');
    reloadOneCharCard(canvasState.char);  // ← 单卡刷新
    closeAdjustModal();
}
```

### cache_version 增量

为保证新图片能立即加载，confirmAdjust 中递增 `char.cache_version`：

```javascript
canvasState.char.adjust_top = ...;
canvasState.char.adjust_right = ...;
canvasState.char.cache_version = (canvasState.char.cache_version || 0) + 1;
```

`img.src` 拼上 `?v=cache_version` → 浏览器看到新 URL → 重新请求。

## 性能对比

|指标 | 全量重渲 | 增量刷新 |
|------|---------|---------|
| DOM 节点变更 | 销毁 + 重建 859 个 | 0 个 |
| HTTP 图片请求 | 0 个（已缓存）| **1 个**（刚修改的）|
| 状态 badge | 重画 859 个 | 移除 1 + 重建 1 |
| 页面闪烁 | 明显 | 几乎无感 |
| 耗时 | 200–1500ms | < 50ms |

## 配合使用的优化

整个 /adjust 页面性能优化链路：

1. **滚动懒渲染**（`8615b91`）— 859 张卡片按需渲染
2. **稳定 cache key**（`5f999aa`）— 复用浏览器缓存
3. **增量单卡刷新**（`1cb4f45`）— confirm 后不重渲全部

三层叠加：从「首屏加载」到「滚动浏览」到「修改单卡」，每步都避免不必要的工作。
