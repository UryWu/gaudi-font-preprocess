# 数据存储说明

> 用户操作触发的数据落盘位置：原图、切割线配置、切割结果字符图。
> 一个批次（图片）的所有数据集中在 `data/sessions/<hash>/` 一个目录下。

## 总览

```
┌─────────────────────────────────────────────────────────────┐
│ 静态目录（图片）                                              │
│   static/uploads/{hash}.png            当前显示图（二值化）   │
│   static/uploads/{hash}_base.png       彩色基准（纠偏+旋转）  │
│   static/uploads/{hash}_original.png   原图副本（重置用）     │
│   static/uploads/original_{filename}   上传时的临时落盘文件   │
├─────────────────────────────────────────────────────────────┤
│ 会话目录（一个批次的所有数据都在这）                          │
│   data/sessions/<hash>/                                      │
│     ├─ cutting.json                切割线 + 绿框配置          │
│     ├─ ocr_annotations.json         OCR 标注（按文件名索引）  │
│     ├─ ocr_tasks/<task_id>.json     OCR 后台任务状态          │
│     ├─ cutting_output/char_NNNN.png 切割后的字符图            │
│     ├─ scaled/scaled_NNNN.png       缩放校正后的字符图        │
│     └─ exported/<时间戳>/           导出训练包（PNG+CSV+映射） │
└─────────────────────────────────────────────────────────────┘
```

## 路径常量

定义在 [config.py](../config.py)：

| 常量 | 值 | 作用 |
|------|-----|------|
| `BASE_DIR` | 项目根目录（脚本所在目录或 exe 所在目录）| 所有路径的基准 |
| `UPLOAD_FOLDER` | `<BASE_DIR>/static/uploads` | 原图+基准图+原图副本 |
| `DATA_FOLDER` | `<BASE_DIR>/data/sessions` | 每批次一个子目录 |
| `OUTPUT_FOLDER` | **同 `DATA_FOLDER`** | 仅作老代码兼容的别名（`config.py:20`）|

> `OUTPUT_FOLDER` 曾经独立指向 `<BASE_DIR>/output`，后来把切割图、缩放图都并进
> `data/sessions/<hash>/`，只保留这个别名不做路径改动。新代码里两者可互换。

## 数据生命周期

```
[上传图片]
  POST /api/upload
  ├─ 保存原图:        static/uploads/original_{filename}
  ├─ 计算哈希:        file_hash = md5(原图)
  ├─ 自动纠偏（可选）: deskew(img)
  ├─ 存原图副本:      static/uploads/{hash}_original.png     ← 始终不变
  ├─ 存彩色基准:      static/uploads/{hash}_base.png         ← 跟随手动旋转更新
  ├─ 二值化 + 缩放:   static/uploads/{hash}.png              ← 当前显示（被旋转覆盖）
  ├─ 检测文本框:      boxes (in-memory)
  └─ 分析切割线:      vertical_lines, horizontal_lines, strip_horizontal_lines

[手动旋转（每次点 ↺/↻）]
  POST /api/rotate
  ├─ 旋转 _base.png: 累积旋转结果（彩色）
  ├─ 二值化+缩放:     覆盖 {hash}.png
  └─ 不更新 boxes / cut_lines（"识别"才更新）

[点「开始识别」]
  POST /api/detect
  ├─ 读取 {hash}.png（当前已旋转的二值化图）
  ├─ 检测 boxes
  ├─ 分析 cut_lines
  └─ 返回前端

[点「存储切割线」]   ← 立即落盘
  POST /api/save_cuts
  └─ 写入: data/sessions/<hash>/cutting.json
     {hash, vertical_lines, horizontal_lines, strip_horizontal_lines, boxes}

[点「加载切割线」]
  GET /api/load_session/<hash>
  └─ 读取 data/sessions/<hash>/cutting.json 覆盖到画布（加载前压撤销栈）

[点「应用切割」]      ← 立即生成字符图
  POST /api/apply_cuts
  ├─ 读取 {hash}.png
  ├─ 按当前 boxes/切线切割
  ├─ 写入: data/sessions/<hash>/cutting_output/char_NNNN.png  (每个字符一张图)
  └─ 返回每片的元数据 (index, x, y, width, height, is_empty, source)

[点「重置」]
  POST /api/reset_image
  ├─ 用 {hash}_original.png 覆盖 {hash}_base.png
  ├─ 重新二值化+缩放 → {hash}.png
  └─ 重置累计旋转角度

[跳转到「缩放校正」]
  POST /api/process_scale
  └─ 读取 data/sessions/<hash>/cutting_output/char_NNNN.png
     缩放+居中处理后写入: data/sessions/<hash>/scaled/scaled_NNNN.png

[点「导出训练包」]
  POST /api/export_annotated
  ├─ 读取 data/sessions/<hash>/scaled/scaled_NNNN.png
  ├─ 颜色反转（白底黑字）
  └─ 写入 data/sessions/<hash>/exported/<时间戳>/
       ├─ *.png                    白底黑字，命名 uniXXXX[_NN].png（同字加 _01/_02）
       ├─ fontlab_<时间戳>.csv       filename / unicode / character / simplified / traditional
       └─ fontlab_<时间戳>.source_map.json   源切图名 → 导出名
     （导出**不再自动清理**过程图；要清盘点工具栏「清理过程图」按钮）
```

## 文件命名约定

| 文件名 | 含义 |
|--------|------|
| `original_{filename}` | 上传时原样落盘的临时文件（名字取自上传文件名，仅供算哈希） |
| `{hash}.png` | 当前显示图（二值化 + 缩放到目标高度） |
| `{hash}_base.png` | 彩色基准图，跟随手动旋转累积 |
| `{hash}_original.png` | 原图副本，仅在「重置」时读取 |
| `data/sessions/<hash>/cutting.json` | 切割线 + 绿框配置 |
| `data/sessions/<hash>/ocr_annotations.json` | OCR 标注（key = 字符文件名） |
| `data/sessions/<hash>/ocr_tasks/<task_id>.json` | OCR 后台任务状态（持久化，跨 Flask 重启） |
| `data/sessions/<hash>/cutting_output/char_{idx:04d}.png` | 切割字符图，idx 从 0000 开始 |
| `data/sessions/<hash>/scaled/scaled_{idx:04d}.png` | 缩放校正后的字符图 |
| `data/sessions/<hash>/exported/<时间戳>/` | 导出训练包（PNG + CSV + source_map） |

## 会话标识（`<hash>`）怎么确定

`<hash>` 就是 session 目录名。它有**两套来源**，取决于数据从哪个入口进来。

### ① 上传图片（页面1 主流程）—— 按**文件内容**算 MD5

```python
# app.py /api/upload
filename = secure_filename(file.filename)          # 文件名只用来存临时副本
file.save(.../"original_{filename}")
file_hash = compute_hash(original_path)            # ← 读的是文件字节
```

```python
# utils/image_processor.py
def compute_hash(filepath):
    """计算文件MD5哈希"""
    hash_md5 = hashlib.md5()
    with open(filepath, "rb") as f:
        for chunk in iter(lambda: f.read(4096), b""):
            hash_md5.update(chunk)
    return hash_md5.hexdigest()                    # 32 位十六进制
```

**文件名不参与哈希**——它只决定那个临时文件叫什么。

### ② 「导入目录」（/annotate 顶部按钮）—— 按**目录路径字符串**算 MD5

```python
# app.py /api/import_characters
dir_path = os.path.dirname(files[0].filename) if files[0].filename else ''
dir_hash = hashlib.md5(dir_path.encode()).hexdigest()[:16]   # 路径字符串，截取 16 位
```

哈希对象是浏览器上传时带的相对目录名，**不是图片内容**；长度是 **16 位**（上传图片是 32 位）。

### 实践结论

| 操作 | 会不会复用原会话 |
|------|-----------------|
| 同一张图重新上传（用原文件） | ✅ 复用，自动加载上次的切割线 |
| 改文件名、内容不变 | ✅ 复用（文件名不参与哈希） |
| 重新压缩 / 截图 / 微信转发 / 改 EXIF | ❌ 字节变了 → **新会话**，之前的标注全看不到 |
| 同一目录再导入一次 | ✅ 复用 |
| 换个目录名导入同样的图 | ❌ 新会话 |

> 最容易踩的是第三行：**转发或截图一次再上传，同一张图就会被当成新批次**。
> 想复用之前的切割线与标注，务必用当初那个原文件。

## 关键约定

- **`{hash}` 的来源见上一节**（上传=内容 MD5 32 位；导入目录=路径 MD5 16 位）。
- **同名文件覆盖**：重复点「应用切割」会用新结果覆盖 `char_NNNN.png`，不会创建新文件。
- **原图永远不变**：`{hash}_original.png` 只在「重置」时**读取**，从不被写入覆盖，保证可还原。
- **导出不再自动清理**：`cutting_output/`、`scaled/`、`ocr_tasks/` 会一直留着便于回溯，
  要清盘得点工具栏「清理过程图」按钮（只清过程目录，不动 `exported/`）。

## 验证示例

```
1. 上传图片
2. 从页面「图片信息」读出哈希前 12 位，例如 c508565e8b8c
3. 文件管理器打开 <项目根>/，应该看到：
   static/uploads/c508565e8b8c.png          (显示图)
   static/uploads/c508565e8b8c_base.png     (基准)
   static/uploads/c508565e8b8c_original.png (副本)
4. 点「存储切割线」
   data/sessions/c508565e8b8c/cutting.json   (新建)
5. 点「应用切割」
   data/sessions/c508565e8b8c/cutting_output/char_0000.png   (新建)
   data/sessions/c508565e8b8c/cutting_output/char_0001.png
   ...
6. 跑「缩放校正」后
   data/sessions/c508565e8b8c/scaled/scaled_0000.png
7. 点「导出训练包」后
   data/sessions/c508565e8b8c/exported/20260912_101530/
       ├─ uni4E00.png ... fontlab_20260912_101530.csv
       └─ fontlab_20260912_101530.source_map.json
```
