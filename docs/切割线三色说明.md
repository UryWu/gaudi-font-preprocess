# 切割布局：三色线作用说明

> 为什么不能只用绿色虚线？红色、蓝色、绿色虚线各扮演什么角色？

## 三色线一览

| 颜色 | 类型 | 来源 | 作用 |
|------|------|------|------|
| 🟥 **红色实线** | 纵向切割线 | 由绿框 x 轴间隙推导 | 把图片切成列 |
| 🟦 **蓝色实线** | 横向切割线 | 由绿框 y 轴间隙推导 | 把每列切成行 |
| 🟩 **绿色虚线** | OCR 文本框 | EasyOCR 原始检测 | 仅作参考提示，不参与切割 |

## 三者的关系示意

```
┌──────────────────────────────────────────────┐
│  原始书法图片                                │
│                                              │
│  ┌─────┐  ┌───┐ ┌─────┐                     │
│  │ 永  │  │ 墨 │ │ 宝  │   ← 绿色虚线：OCR  │
│  └─────┘  └───┘ └─────┘     检测的原始边界 │
│  ┌──┐ ┌──┐ ┌─────┐                            │
│  │书│ │ 法│ │ 之  │                            │
│  └──┘ └──┘ └─────┘                            │
│                                              │
│  ┊    ┊     ┊     ┊       ← 红色线：纵向列边界 │
│                                              │
│  ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌   ← 蓝色线：横向行边界  │
└──────────────────────────────────────────────┘
```

## 为什么不能只用绿色虚线？

绿色虚线是 OCR（EasyOCR）的原始检测结果，存在三个问题：

1. **OCR 边界不准**：可能把一个字切成两半、也可能把两个字合并为一个
2. **每个字符大小不一致**：训练字体需要统一尺寸，直接用 OCR 边界会导致每个字框大小不一样
3. **OCR 漏检**：缺字的地方没有绿框，但切割网格仍然需要一个空格子（后续「切割调整」会标记为空白切片让你删）

## 红/蓝线的实际作用

切割算法见 [utils/cut_analyzer.py](../utils/cut_analyzer.py)：

- **红色线** = 取所有绿框在 x 轴上的「中位间隙」作为列边界
- **蓝色线** = 取每列内绿框在 y 轴上的「中位间隙」作为行边界

结果就是一个 **统一规则的网格**，每个格子是一个字符图片。算法不直接用绿框边界，而是用绿框**间隙的中点**，所以更稳定。

> 蓝色线是**按列独立管理**的（`stripHorizontalLines` 结构）：每列有自己的横向切割线集合，行高可以不同。

## 切割时的实际逻辑（app.py:226-270）

```python
for strip in strip_horizontal_lines:
    h_lines = strip['horizontal_lines']  # 蓝色线（按列）
    for j in range(len(vertical_lines) - 1):  # 红色线
        # 网格 (j, i) = 一个字符
        x1, x2 = vertical_lines[j], vertical_lines[j+1]
        y1, y2 = h_lines[i], h_lines[i+1]
        cut_one_char(x1, y1, x2, y2)
```

**绿色虚线只是参考提示，不参与切割**。可随时切换显示/隐藏。

## 什么时候可以「只要绿线」？

理论上 OCR 100% 准确时可以直接用绿框边界，但 EasyOCR 在书法字（特别是草书、行书）上准确率远达不到 100%，所以走「绿框 → 推算网格 → 手动修正网格」这条路更稳。蓝/红线给你手动修正的入口：

| 场景 | 操作 |
|------|------|
| OCR 切错字位置 | 左键拖动蓝/红线 |
| OCR 漏字，需要加行 | 双击图片添加蓝线 |
| OCR 漏列，需要加列 | Shift + 双击添加红线 |
| 某行/列是多余的 | Alt + 左键点击删除 |

## 总结

| 角色 | 一句话 |
|------|--------|
| 🟩 绿色虚线 | OCR 给的「**建议**」 |
| 🟥🟦 红蓝实线 | 经过校正的「**切割方案**」 |

**绿色虚线仅供参考，红蓝实线才是真正决定怎么切的。**
